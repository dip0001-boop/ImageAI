# imageAI

imageAI is an AI image creation chatbot powered by the FLUX API.

It provides a ChatGPT/Gemini-style interface where users can describe an image and receive an AI-generated image.

---

## Features

- AI image generation
- Chat-style interface
- Previous chat history
- Local chat saving
- Dark SaaS dashboard UI
- Secure API key handling
- Render deployment support
